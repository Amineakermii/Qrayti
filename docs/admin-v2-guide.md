# Admin v2 — استعمال قرايتي

افتح `/admin/` بكلمة السر الحالية. الزرين بالأعلام يبدّلوا لغة الإدارة بين العربية والإنجليزية ويحفظوا اختيارك.

زر الشمس/القمر بجانب الأعلام يبدّل بين الوضع الفاتح والداكن ويحفظ اختيارك في هذا المتصفح. ألوان الإدارة أزرق قرايتي؛ هذا الاختيار لا يغيّر ألوان الموقع للزوار، ولا يمسح ما تكتبه في المحرّر.

## كلمة أو صورة في الموقع

1. افتح **محرّر الموقع / Website editor**.
2. اختار الصفحة من **كل صفحات قرايتي / All Qrayti pages**: الرئيسية، الإجازات، المواد، المعدّل، اختبار اللغات، وصفحة الأساتذة بالفرنسية أو الإنجليزية. يمكن مواصلة التنقّل داخل المعاينة.
3. اضغط **اختار عنصر / Select element**، ثم النص أو الصورة، أو لوّج في **كلمات الصفحة / Words on this page** واختار النص من النتائج. البحث يشمل النوافذ المخفية وتلميحات الإدخال. أزرار شكون إحنا، بديس، تحميل التطبيق والبحث تفتح النوافذ في المعاينة.
4. عدّل واضغط **طبّق في المعاينة**. يمكن تطبيق نفس النص في الصفحة فقط أو كل الصفحات.
5. **حفظ المسودة** يحفظ عملك من غير نشره. **معاينة ونشر** يطلب تأكيدًا قبل إظهاره للزوار.

خانات الرئيسية والهوية تتعمّر بالنص الموجود فعلاً بعد تحميل المعاينة. وعند اختيار نص من المعاينة، خانة التعديل تتفتح وفيها النص الحالي جاهزًا للتعديل. مجرّد فتح المحرّر لا يحفظ ولا ينشر أي تغييرات.

التعديل نص عادي، وليس HTML أو كود. النصوص تتطابق مع النص الأصلي والصفحة؛ إذا تغيير برمجي لاحق بدّل النص الأصلي، اختاره مجددًا. لا يغيّر محرّر الموقع النصوص الأصلية داخل APK مثبتة؛ إدارة الكور تعتمد على الكاتالوغ المشترك.

تعديلات صفحة الأساتذة مرتبطة باللغة المختارة؛ تعديل الفرنسية لا يبدّل الإنجليزية إلا إذا تختار كل الصفحات. بيانات الأستاذ، الملفات الخاصة، رموز الدعوة وقيم الخانات لا تدخل في قائمة الكلمات. نصوص الإدارة نفسها ليست محتوى عامًا قابلًا للتعديل هنا. عناوين الكور وبياناتها الدائمة تتعدّل من **الكور والملفات**.

## الصور والقوالب

ارفع الصور في **مكتبة الصور** ثم اختارها للشعار أو الرئيسية أو من المعاينة. الصور PNG / JPG / WebP حتى 8 MB. استعمل فقط صورًا عندك حق استعمالها. رفع الصورة وحده لا يغيّر الموقع.

القوالب الجاهزة: التصميم الحالي، ونفس التصميم مع حركة إضافية. القوالب الجديدة مختلفة التخطيط مازالت قيد التطوير ومعلّمة بذلك. تغيير القالب لا ينشر تلقائيًا.

## الكور

**إضافة كور**: اختار الإجازة والسنة والسداسي والمادة، ثم الملفات ومصادرها. أكد الإذن بالنشر. الحالة الافتراضية مسودة؛ اختر منشور كي تظهر في الكاتالوغ. أبقِ صفحة الإدارة مفتوحة حتى ينتهي الرفع؛ يمكن التنقّل بين أقسامها أثناء ذلك.

**الكور والملفات**: البحث يشمل الملف والمادة والجامعة والأستاذ. الملفات المرفوعة يمكن نقلها بين السياقات وتعديل بياناتها. المكتبة الأصلية تدعم تعديل الاسم والشابتر والمصدر وإخفاء الملف. الإخفاء يزيله من فهرس الموقع ولا يمحو الملف الأصلي أو النسخ التي سبق تحميلها. تغييرات الكور تحفظ مباشرة، ولا تنتظر زر نشر الموقع.

## بديس وحما غراب

لكل قسم إعداد ظهور وتعديل نصوصه. الحفظ يحدّث الإعدادات مباشرة ويحافظ على إعداد الظهور الحالي ما لم تغيّره بنفسك.

بديس يحافظ على شخصية الكتاب مع حركات تفاعلية؛ حما أصبح غرابًا مرسومًا بدل الإيموجي. هذا التحديث لا يفعّل محادثات معطّلة ولا يغيّر أقوالك المحفوظة. بطاقات المواد تستعمل رسومات المواد الموجودة في التطبيق، ويمكن تغيير صورها من المحرّر. رابط **فهرس المواد** أزيل من أسفل الرئيسية فقط؛ المواد والكور لم تُحذف.

## الرجوع والحماية

سجل النشر يعرض آخر 30 نسخة منشورة. استرجاع نسخة يحوّلها لمسودة؛ عاينها ثم انشرها. يمكن تنزيل نسخة JSON من محتوى الموقع والكاتالوغ. هذه نسخ بيانات وليست نسخًا من ملفات الكور نفسها. إذا حفظ شخص من جلسة أخرى، ترفض الإدارة الكتابة فوق تغييره وتطلب إعادة التحميل.

الواجهة القديمة محفوظة في `/admin/legacy` للاسترجاع، وليست الواجهة الموصى بها.

## Local verification (developers)

Tests only target `127.0.0.1:8789`; never substitute a production URL. Seed isolated local storage with `wrangler d1 execute qrayti-catalog --local --persist-to .wrangler/admin-v2-test --file database/schema.sql`, then run Pages dev on port 8789 using that persist directory and the dummy test bindings `ADMIN_PASSWORD=local-admin-test-only` / `ADMIN_SESSION_SECRET=local-admin-test-signing-only`.

Run `node --test tests/admin-v2.test.mjs`, then `node tests/admin-v2.browser.mjs`. Browser tests accept PLAYWRIGHT_MODULE and CHROMIUM_PATH environment variables. Generated screenshots go to ignored `test-results/`. No automated test mutates production content.
