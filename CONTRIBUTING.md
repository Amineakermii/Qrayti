# Contributing to Qrayti

Thanks for helping Tunisian students learn more easily.

1. Open an issue before a large feature.
2. Fork the repository and create a focused branch.
3. Run `gradle :app:testDebugUnitTest :app:lintDebug`.
4. Explain the student problem, your change and how you tested it.

Do not commit course files, APKs, credentials, signing material, private student data or production Cloudflare configuration. For a learning resource, provide the university or institution, author or instructor when known, public source, and proof that redistribution is allowed. Paid books and unlicensed commercial material are not accepted.
